## Назначение

Программа читает n от 1 до 8 и n чисел типа double в массив ёмкостью 9.
Затем заменяет все элементы на fabs от них, удаляет элементы с чётными
исходными индексами 0, 2, 4 и далее и добавляет ноль в конец.
Если после удаления массив пуст, выводится `массив пуст` и вставка не выполняется.

## Сборка

Команда выполняется из каталога `lr-01/extra/`:

```bash
gcc -Wall -Wextra -Werror -o app src/main.c src/array.c -lm
```

## Запуск

```bash
./app
```

Ввод: длина n, затем n вещественных чисел. Числа разделяются пробелами
или переводами строки, десятичный разделитель — точка.
Вывод: итоговый массив одной строкой с тремя знаками после запятой.
При ошибке чтения или длине вне 1–8 выводится `ошибка ввода`, код завершения 1.
В остальных случаях код завершения 0.

Пример ввода:

```text
5
-1 -2 -3 -4 -5
```

Вывод:

```text
2.000 4.000 0.000
```
