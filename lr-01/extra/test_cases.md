# Тесты дополнительного задания. Вариант 8

Порядок: модуль, удаление чётных исходных индексов, вставка нуля в конец.
Начальная длина 1–8, ёмкость 9. Неполный ввод проверяется из файла с концом потока.

## 1. Обычный массив

Группа: нормальные данные.

Ввод:

```text
5
-1 -2 -3 -4 -5
```

Ожидаемый вывод:

```text
2.000 4.000 0.000
```

Код завершения: `0`.

Назначение: Проверка всех трёх операций: сохраняются элементы с исходными индексами 1 и 3.

## 2. Дробные числа и ноль

Группа: нормальные данные.

Ввод:

```text
4
10 0 -20 -0.5
```

Ожидаемый вывод:

```text
0.000 0.500 0.000
```

Код завершения: `0`.

Назначение: Проверка нуля и модуля дробного отрицательного числа.

## 3. Минимальная длина: n = 1

Группа: граничные данные.

Ввод:

```text
1
-8
```

Ожидаемый вывод:

```text
массив пуст
```

Код завершения: `0`.

Назначение: Единственный элемент с индексом 0 удаляется; вставка не выполняется.

## 4. После удаления остаётся один элемент

Группа: граничные данные.

```text

```

Ожидаемый вывод:

```text

```

Код завершения: `0`.

Назначение: Проверка минимального непустого результата удаления.

## 5. Максимальная длина: n = 8

Группа: граничные данные.

Ввод:

```text
8
-1 -2 -3 -4 -5 -6 -7 -8
```

Ожидаемый вывод:

```text
2.000 4.000 6.000 8.000 0.000
```

Код завершения: `0`.

Назначение: Проверка верхней границы и исходной чётности индексов.

## 6. Длина меньше допустимой

Группа: ошибочные данные.

Ввод:

```text
0
```

Ожидаемый вывод:

```text

```

Код завершения: `1`.

Назначение: Отклоняется длина меньше 1.

## 7. Длина больше допустимой

Группа: ошибочные данные.

Ввод:


Код завершения: `1`.

## 10. Недостаточно элементов

Группа: ошибочные данные.

Ввод:

```text
3

```

Ожидаемый вывод:

```text

```

Код завершения: `1`.

Назначение: Входной файл заканчивается после числа 2; третий элемент отсутствует.
