# ЛР 01. Два массива и их модификация

- Вариант: 6

## Назначение

Программа читает массив A и строит массив B по формуле
`B[i] = 5.5 * sin(i * h) + cos(a * x + i * h)`.
Из B удаляются положительные элементы строго левее последнего отрицательного.
В начало A вставляется копия элемента с индексом 1, после чего значения
больше 10 заменяются на 10, а значения меньше -10 — на -10.
Программа выводит исходные массивы и результаты всех трёх операций.

## Ограничения

- Длины `n` и `m` — целые числа от 1 до 20, задаются независимо.
- Ёмкость каждого массива — 20 элементов; память динамически не выделяется.
- Элементы A и параметры `a`, `x`, `h` имеют тип `double` и читаются через `%lf`.
  Отдельные числовые диапазоны для них заданием не установлены.
  Углы для `sin` и `cos` задаются в радианах.
- При неудачном чтении требуемых чисел или длине вне диапазона выводится
  `ошибка ввода`; программа завершается с кодом 1 до вывода массивов.
- При отсутствии отрицательных элементов B удаление не выполняется.
- При `n = 20` нет места для вставки. При `n = 1` нет элемента A[1].
  Отказ в одной операции не отменяет последующие операции.
- При успешном чтении программа завершается с кодом 0, в том числе
  если удаление или вставка невозможны.

Уточнение варианта: в таблице написано «копия первого элемента (индекс 1)».
В программе используется явно указанный индекс 1, то есть второй элемент
при нумерации с нуля. Так же работает вставка в предоставленном примере.

## Сборка

Команда выполняется из каталога `lr-01/`:

```bash
gcc -Wall -Wextra -Werror -o app src/main.c src/arrays.c -lm
```

`src/arrays.h` содержит ёмкость и прототипы, `src/arrays.c` — функции ввода,
построения, поиска, модификации и вывода; `src/main.c` — порядок вызовов
и сообщения. В main нет циклов по массивам и формулы варианта.

## Запуск

```bash
./app
```

Ввод — с клавиатуры. Программа не печатает подсказки; числа нужно вводить
в указанном ниже порядке. Можно сохранить ввод в `input.txt` и выполнить:

```bash
./app < input.txt
```

## Формат ввода и вывода

Ввод:

1. Целое `n` — длина A.
2. `n` вещественных чисел — элементы A.
3. Целое `m` — длина B.
4. Три вещественных числа `a`, `x`, `h` — параметры формулы B.

Числа разделяются пробелами или переводами строки. Десятичный разделитель —
точка. Элементы B пользователь не вводит.

Вывод состоит из десяти строк: подписи `A:`, `B:`, `B после удаления:`,
`A после вставки:`, `A после изменения:` чередуются со строками элементов
или сообщений. Элементы выводятся с тремя знаками после запятой (`%.3lf`),
между ними один пробел, в конце строки пробела нет. Сравнения выполняются
по значениям double без eps; округление применяется только при печати.

Сообщения:

- `ошибка ввода` — число не прочитано либо n или m вне диапазона 1–20.
- `операция невозможна` — в B нет отрицательного элемента либо при вставке
  в A отсутствует элемент с индексом 1.
- `нет места для вставки` — длина A уже равна 20.
- `массив пуст` — общий случай нулевой длины после удаления; для варианта 6
  недостижим, поскольку последний отрицательный элемент сохраняется.

Пример ввода:

```text
4
12 -14 10 -10
8
0 0 1
```

Вывод для этого примера:

```text
A:
12.000 -14.000 10.000 -10.000
B:
1.000 5.168 4.585 -0.214 -4.816 -4.990 -0.577 4.367
B после удаления:
-0.214 -4.816 -4.990 -0.577 4.367
A после вставки:
-14.000 12.000 -14.000 10.000 -10.000
A после изменения:
-10.000 10.000 -10.000 10.000 -10.000
```

## Тесты

Тесты приведены в файле [`test_cases.md`](test_cases.md). Набор содержит:

- нормальные данные: разные длины, все три операции, ненулевые a и x;
- граничные данные: n и m равны 1 и 20, n = 19, отсутствие ориентира,
  пустой участок удаления, отсутствие удаляемых элементов, один оставшийся
  элемент, значения у границ -10 и 10;
- ошибочные данные: буквы вместо чисел, недопустимые длины, неполный ввод.
