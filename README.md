## Основное задание: вариант 6

Массив A вводится с клавиатуры. Массив B вычисляется по формуле:

```c
B[i] = 5.5 * sin(i * h) + cos(a * x + i * h);
```

Из B удаляются положительные элементы строго левее последнего отрицательного.
В начало A вставляется копия A[1], затем значения A ограничиваются
диапазоном от −10 до 10. Оба массива имеют ёмкость 20 элементов.
Вставка трактуется по явно указанному в условии индексу 1.

Сборка из корня репозитория:

```bash
gcc -Wall -Wextra -Werror -o lr-01/app lr-01/src/main.c lr-01/src/arrays.c -lm
```

Запуск:

```bash
./lr-01/app
```

Пример ввода:

```text
4
12 -14 10 -10
8
0 0 1
```

## Дополнительное задание: вариант 8

Программа заменяет элементы на их модули, удаляет элементы с чётными
исходными индексами и добавляет ноль в конец. Начальная длина — от 1 до 8,
ёмкость — 9 элементов. Если после удаления массив пуст, вставка не выполняется.

Сборка из корня репозитория:

```bash
gcc -Wall -Wextra -Werror -o lr-01/extra/app lr-01/extra/src/main.c lr-01/extra/src/array.c -lm
```

Запуск:

```bash
./lr-01/extra/app
```

Пример ввода:

```text
5
-1 -2 -3 -4 -5
```

Ожидаемый вывод:

```text
2.000 4.000 0.000
```
